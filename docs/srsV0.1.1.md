# Star Everything SRS V0.1.1

- 状态：前端重构需求补充
- 适用范围：桌面端前端信息架构、页面组织与交互
- 产品基线：[`docs/srs.md`](./srs.md) 的 V1 产品需求继续有效；本文不替换、不修改其数据、安全及业务规则。
- 术语：以根目录 [`GLOSSARY.md`](../GLOSSARY.md) 为准。
- 技术约束：TypeScript、React、Tauri 2；本地 SQLite 和版本化 JSON 备份行为不变。

## 1. 目标

将当前以收藏夹导航和主内容组成的双栏界面重构为桌面收藏工作台。重构应强化四个明确工作页面、快速查找、文件夹浏览和一致的新增/编辑体验，不改变收藏数据、持久层、备份格式或现有业务规则。

## 2. 全局导航与入口

- 每次应用启动显示球体入口，背景使用 Scanner 动态效果。
- 激活球体后显示 CardSwap 页面切换器；用户选择后进入对应工作页面。
- 工作区左侧显示竖向 GooeyNav，包含筛选页、收藏夹页、回收站和设置四项。
- 工作区任意页面可用 `Ctrl+K` 打开 CardSwap 覆盖层。方向键切换选择，Enter 确认，Escape 关闭并返回原页面。
- 焦点位于文本输入控件时，不得拦截 `Ctrl+K` 的输入行为；切换器关闭后焦点应回到打开前的位置。
- Scanner 背景贯穿入口、页面切换器和四个工作页面，不能拦截页面交互。
- Scanner 完整动效默认开启。设置提供减少动效版本；动效偏好由应用设置控制，不自动服从操作系统减少动态效果偏好。

## 3. 筛选页

### 目的

查找和筛选全部收藏条目。

### 内容与行为

- 显示匹配结果数量、搜索框、排序/筛选控件、平台标签筛选、收藏表格和新增收藏操作。
- 表格信息覆盖标题/主要值、网址、作者、平台标签、内容标签、收藏夹路径和保存时间；可根据空间将次要值放在标题单元格内。
- 支持按表格列排序，默认顺序维持最新创建优先。
- 排序和筛选使用类似电子表格表头菜单的统一交互。平台标签、内容标签和收藏夹路径支持多选筛选。
- 同一筛选维度多选按 OR；不同维度按 AND。收藏夹筛选默认包含所选收藏夹的子孙收藏夹。
- 搜索继续覆盖标题、网址、作者、平台标签、内容标签和收藏夹路径，并保持大小写不敏感的子串匹配。
- 显示已应用筛选条件，并提供清除筛选操作。
- 表格显示全部收藏条目，不得因分页或默认过滤而静默隐藏记录。
- 新增收藏使用共享的创建/编辑弹窗。

### 状态

必须涵盖加载中、数据读取失败、无收藏、无匹配结果、搜索/筛选生效、长标题/长网址、多标签、多收藏夹归属，以及作者-only 条目。

## 4. 收藏夹页

### 目的

浏览收藏夹层级并查看所选收藏夹中的收藏条目。

### 内容与行为

- 在同一页面展示收藏夹目录树和所选收藏夹的收藏条目。
- 目录树支持展开/收起、明显的当前选择态、条目数量；目录较长时自身独立滚动。
- 每个收藏夹提供操作菜单：新建子收藏夹、重命名、移动、删除。
- 删除必须展示影响范围，并保留现有两种行为：条目移入 Home 后删除目录子树，或将目录子树及条目作为删除组移入回收站。
- 选择收藏夹后，条目视图包含所选收藏夹及其所有子孙收藏夹中的条目；多重收藏夹归属保持不变。
- 收藏夹页复用筛选页的条目表格、排序筛选交互及新增收藏弹窗，不另建平行实现。

## 5. 回收站

### 目的

恢复或永久清理已删除收藏和收藏夹删除组。

### 内容与行为

- 显示回收站保留状态、每项剩余保留天数、恢复、单项永久清理和立即清空回收站操作。
- 使用与筛选页相同的表格及排序/筛选交互模式；筛选字段针对回收站项目，包括名称、类型、删除/到期时间和剩余天数。
- 不展示不适用于回收站数据的活动收藏筛选字段。
- 永久清理和清空回收站均须二次确认。
- 恢复条目或收藏夹删除组后遵循 V1 既有数据恢复规则；默认 30 天保留及到期清理策略不变。
- 回收站为空时展示既有空状态。

## 6. 设置

保留 V1 已有设置和数据管理能力，按任务分组：

- 外观：跟随系统/浅色/深色主题；Scanner 减少动效开关。默认完整动效，应用内设置为动效行为的权威设置。
- 识别：元数据识别启用/停用。
- 标签：平台标签和内容标签管理。
- 数据：完整 JSON 备份导出、合并导入、替换导入；替换导入继续要求明确确认。
- 回收站：显示保留期限状态并提供进入回收站的入口。

## 7. 新增与编辑收藏

- 筛选页和收藏夹页的新增操作打开同一弹窗；编辑复用相同表单。
- 保留分享网址/文案识别、标题、网址、作者、平台标签、内容标签和多收藏夹归属字段。
- URL 与作者至少填写一项；允许 URL-only、author-only 及两者并存。
- 识别结果不得覆盖用户已输入值；识别失败、离线或平台页面变化均不得阻止手动保存。
- 保留完整原始 URL 查询参数，不登录平台、不上传用户收藏、不调用私有签名接口、不绕过验证或反爬。
- 新增收藏主要按钮采用 SpecularButton 所示边缘光晕处理；保持控件语义、可见焦点和键盘可操作性。

## 8. 视觉、动效与无障碍要求

- 视觉参考使用用户指定的 React Bits：Scanner、CrystalizedBall、CardSwap、GooeyNav、SpecularButton。
- Scanner 是装饰性背景层，不承载信息，不获取控件指针事件。内容区域必须有足够遮罩/表面层，确保文字、边框和焦点状态在浅色/深色主题均清楚可读。
- 完整扫描效果默认开启；设置中的减少动效版本应静态或显著降低运动。减少动效设置覆盖系统偏好。
- 球体入口、CardSwap、对话框、收藏夹树和表格排序筛选控件均需键盘可达、名称明确、焦点可见；关闭覆盖层/弹窗后焦点回到触发位置。
- 动画不得延迟页面可用时间；动效用于说明入口、切页和选择状态。
- 桌面主要验收窗口为 1080x720，最低支持窗口为 720x520；窄窗口下不得出现不可访问的操作或页面级横向溢出。

## 9. 业务与技术边界

- `docs/srs.md` 的 V1 业务规则、安全要求、数据模型、SQLite schema、备份格式和导入行为继续为权威来源。
- 不新增账户、云同步、收藏数据上传、产品内 AI/Agent/MCP 或平台订阅能力。
- 前端重构不得改变 `CollectionRepository` 契约或 `src/domain` 业务行为。
- 指定的 React Bits 命令是实现参考；实际引入依赖前仍需检查兼容性、许可证、打包体积和 Tauri CSP。

## 10. 验收摘要

- 每次启动可从球体入口通过页面切换器进入四个工作页面；工作区 GooeyNav 能在四页间切换。
- `Ctrl+K` 可键盘打开页面切换器；方向键、Enter、Escape 行为正确，且不会破坏文本输入。
- 筛选页与收藏夹页共享同一条目表格和新增/编辑弹窗；所有条目均可浏览，排序筛选符合 V1 的 AND/OR 规则。
- 收藏夹页可管理树并查看所选目录子树中的收藏；删除影响确认及恢复行为正确。
- 回收站可按其字段排序/筛选、恢复、确认永久清理，并正确显示保留状态。
- 设置保留主题、识别、标签和备份行为，新增减少动效偏好。
- Scanner 在四个页面和入口均显示，完整效果默认启用；减少动效设置生效且界面仍可读。
- V1 域逻辑、存储和备份测试不回归；前端测试覆盖新增的切页、快捷键、排序筛选、对话框共享及动效偏好。

## 11. 尚未固定的实现细节

表格每列的精确宽度、页面转场时长、收藏夹计数口径、排序优先级菜单的具体样式，以及达到何种条目数量才引入虚拟化，留给实现阶段在不改变上述行为的前提下决定。
